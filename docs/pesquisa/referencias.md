# Referências de Design - EduTrack AI

Pesquisa de templates no Figma Community para inspirar o desenvolvimento visual do EduTrack AI.

## 1. Educational Dashboard

**Link:** https://www.figma.com/design/7W3D9pYLGGuRbtvfRmt2aa/Educational-Dashboard--Community-?node-id=0-1&p=f&t=wIw9pgfBiLrrlLL1-0

Gostei bastante do calendário de progresso, que mostra as atividades futuras de forma organizada, e também do gráfico de performance combinado com os círculos de progresso individuais (por matéria/módulo). Essa combinação visual passa uma ideia clara de evolução do aluno de forma rápida.

## 2. Tasky - Task and Time Management Dashboard

**Link:** https://www.figma.com/design/Yqpjji7EvI20gcG0QBTIjE/Tasky---Task-and-Time-Management-Dashboard--Community-?node-id=0-45&t=DRiEaWvZoolhwWQM-0

Curti o design eficiente e harmônico do template como um todo — o layout é limpo, com boa organização entre sidebar, cards de resumo e listas, sem parecer poluído. É uma boa referência de como estruturar informação sem sobrecarregar a tela.
